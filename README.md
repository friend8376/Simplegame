# ร้านน้ำหอมมหัศจรรย์ (Perfume Maker)

เกมเปิดร้านน้ำหอมสุดน่ารัก ผสมกลิ่นให้ถูกใจลูกค้า แล้วพาร้านให้อยู่รอดไปนานที่สุด

เขียนด้วย Python ไฟล์เดียว ใช้แค่ `tkinter` ที่มากับ Python ไม่ต้องติดตั้ง library อื่น

## วิธีรัน

ต้องมี Python 3.8 ขึ้นไป (ใน Windows และ macOS มี tkinter มาให้แล้ว)

```bash
python main.py
```

> ถ้าใช้ Linux แล้วขึ้นว่าไม่มี tkinter ให้ติดตั้งก่อน เช่น `sudo apt install python3-tk`

## เป้าหมายของเกม

- ลูกค้าเข้าร้านวันละ 5 คน แต่ละคนอยากได้น้ำหอมกลิ่นต่างกัน
- ผสมน้ำหอมให้ตรงใจลูกค้าเพื่อหาเงิน
- ทุกสิ้นวันต้องจ่าย **ค่าเช่าร้าน** และค่าเช่าจะแพงขึ้นทุกวัน
- ถ้าเงินไม่พอจ่ายค่าเช่า ร้านจะปิดกิจการ (เกมจบ)
- พยายามเปิดร้านให้ได้หลายวันที่สุด!

## วิธีเล่น

### 1. เลือกเจ้าของร้าน

ก่อนเริ่มเกมให้เลือกเจ้าของร้าน 1 ตัว แต่ละตัวมีความสามารถพิเศษไม่เหมือนกัน

| ตัวละคร | ความสามารถพิเศษ |
|---|---|
| **โมจิ** (กระต่าย) | ลูกค้าอดทนรอได้นานขึ้น 40% |
| **เนโกะ** (แมว) | เริ่มเกมด้วยเงิน 180฿ (ปกติ 100฿) และค่าเช่าร้านถูกลง 20% |
| **ฮันนี่** (หมี) | ได้ทิปและโบนัสคอมโบ 2 เท่า |
| **คิตสึ** (จิ้งจอก) | ได้โบนัสสูตรลับ 2 เท่า และสมุดสูตรบอกวัตถุดิบให้ 1 อย่าง |

### 2. อ่านความต้องการของลูกค้า

ทางขวาของจอจะมีลูกค้าบอกว่าอยากได้กลิ่นแบบไหน และมี **แถบกลิ่น 5 แบบ**

ดอกไม้ · ส้ม · ไม้ · หวาน · สดชื่น

แต่ละแถบมี **รูปหัวใจ** บอกตำแหน่งที่ลูกค้าต้องการ เป้าหมายคือเติมแถบสีให้ไปถึงหัวใจทุกแถบ ถ้าแถบไหนตรงแล้วหัวใจจะเปลี่ยนเป็นสีชมพูและเต้นตุบๆ

### 3. หยดวัตถุดิบลงขวด

คลิกวัตถุดิบจากชั้นวางทางซ้าย (หรือกดเลข `1`–`0`) เพื่อหยดลงขวด ใส่ได้สูงสุด 12 หยด

| วัตถุดิบ | กลิ่นที่ได้ | ราคา/หยด | ได้มาเมื่อ |
|---|---|---|---|
| กุหลาบ | ดอกไม้ +++ หวาน + | 3฿ | เริ่มต้น |
| มะนาว | ส้ม +++ สดชื่น + | 1฿ | เริ่มต้น |
| ไม้จันทน์ | ไม้ +++ | 4฿ | เริ่มต้น |
| วานิลลา | หวาน +++ | 2฿ | เริ่มต้น |
| มินต์ | สดชื่น +++ | 1฿ | เริ่มต้น |
| ลาเวนเดอร์ | ดอกไม้ + สดชื่น ++ | 2฿ | เริ่มต้น |
| ส้มเขียวหวาน | ส้ม ++ หวาน + | 1฿ | วันที่ 2 |
| มะลิ | ดอกไม้ ++ สดชื่น + | 3฿ | วันที่ 3 |
| ซีดาร์ | ไม้ ++ สดชื่น + | 3฿ | วันที่ 4 |
| มัสก์ | ไม้ + หวาน ++ | 4฿ | วันที่ 5 |

ด้านบนขวดจะบอกว่า **ตรงกลิ่นกี่ %** และได้กี่ดาว ส่วนเจ้าของร้านกับขวดจะยิ้มเมื่อผสมได้ดี

### 4. ส่งมอบให้ลูกค้า

กดปุ่ม **ส่งมอบ!** (หรือ `Enter`) ต้องใส่อย่างน้อย 3 หยด ลูกค้าจะให้ดาวตามความตรงของกลิ่น

| ความตรงของกลิ่น | ดาว | ราคาขาย |
|---|---|---|
| 90% ขึ้นไป | ★★★ | ×1.8 |
| 75–89% | ★★ | ×1.2 |
| 55–74% | ★ | ×0.6 |
| ต่ำกว่า 55% | – | ลูกค้าไม่ซื้อ |

กำไร = ราคาขาย + โบนัสต่างๆ − ต้นทุนวัตถุดิบ

> ราคาน้ำหอมตั้งต้นคือ 60฿ และขึ้นวันละ 5฿

## โบนัสและเทคนิค

- **ทิปทำไว:** ได้ 2 ดาวขึ้นไป ยิ่งส่งเร็วยิ่งได้ทิปเยอะ
- **เพอร์เฟกต์:** ตรงกลิ่น 97% ขึ้นไป ได้เพิ่มอีก 20฿
- **คอมโบ:** ได้ 3 ดาวติดกันหลายคน โบนัสจะเพิ่มขึ้นเรื่อยๆ (ถ้าได้น้อยกว่า 3 ดาว คอมโบจะหาย)
- **ความอดทน:** ลูกค้ามีแถบความอดทน ถ้าหมดก่อนส่งมอบ ลูกค้าจะเดินออกไป และเสียวัตถุดิบที่ใส่ไปแล้ว
- **ประหยัดต้นทุน:** มะนาว มินต์ และส้มเขียวหวานราคาแค่ 1฿ ส่วนไม้จันทน์กับมัสก์แพงที่สุด
- ถ้าหยดผิด กด **เอาออก 1** (`Backspace`) หรือ **เททิ้ง** (`Esc`) ได้ฟรี เพราะต้นทุนจะคิดตอนส่งมอบเท่านั้น

## สูตรลับ

มีสูตรลับซ่อนอยู่ 5 สูตร ถ้าในขวดมีวัตถุดิบ **ครบ 3 อย่าง** ตามสูตร และลูกค้าให้อย่างน้อย 1 ดาว จะได้โบนัสเพิ่ม 25฿

เปิด **สมุดสูตรลับ** ได้โดยกด `R` หรือคลิกป้ายมุมขวาบน ในสมุดมีคำใบ้ของสูตรที่ยังไม่เจอ และตอนเปิดสมุดอยู่ เวลาของลูกค้าจะหยุดเดิน

สูตรที่ค้นพบแล้วจะถูกบันทึกไว้ เล่นรอบหน้าก็ยังอยู่

## ปุ่มลัด

| ปุ่ม | การทำงาน |
|---|---|
| `1`–`9`, `0` | หยดวัตถุดิบช่องที่ 1–10 |
| `Enter` / `Space` | ส่งมอบ / ไปต่อ |
| `Backspace` | เอาออก 1 หยด |
| `Esc` | เททิ้งทั้งหมด |
| `R` | เปิด/ปิดสมุดสูตรลับ |
| `←` `→` | เลือกตัวละคร (ในหน้าเลือกตัวละคร) |

## การบันทึกข้อมูล

เกมจะบันทึกสถิติจำนวนวันที่ดีที่สุดของตัวละครแต่ละตัว และสูตรลับที่ค้นพบ ไว้ในไฟล์ `perfume_save.json` ข้างๆ `main.py`
ถ้าอยากเริ่มใหม่ทั้งหมด ให้ลบไฟล์นี้ทิ้ง
